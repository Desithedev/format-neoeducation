# Mẫu định dạng NEO

Đã có **`neo-template.tex`**, chuẩn hóa từ mẫu LaTeX người dùng cung cấp. Đây là nguồn thiết kế chính cho palette, header/footer có Facebook, macro câu/đáp án, bảng code và cỡ chữ. Xem [quy cách template](../../references/template-neo.md).

Sao chép file này làm nguồn của đề, chèn nội dung thật giữa `\begin{document}` và `\end{document}`; sao chép kèm watermark và các tài nguyên code/ảnh. File chỉ là khung, không chứa câu minh họa hoặc metadata kỳ thi mặc định.

Tài liệu bổ sung có thể đặt vào đây nếu có:

| Tên file | Nội dung |
| --- | --- |
| `reference.docx` | Mã LaTeX mẫu: preamble, macro, header/footer và bố cục |
| `format-requirements.docx` | Yêu cầu định dạng gốc |
| `prompt-source.docx` | Prompt thao tác gốc để đối chiếu |

Các DOCX trên chưa được cung cấp, nhưng **không còn là điều kiện bắt buộc** vì đã có mẫu `.tex` được người dùng duyệt. Nếu nhận phiên bản mẫu mới, chỉ rõ file thật và đối chiếu trước khi thay nguồn thiết kế.

Mẫu chứa câu minh họa không phải đề đầu vào. Không lấy số câu, nội dung hoặc thông tin Hà Tĩnh/2026/0906 của mẫu chat làm mặc định cho đề mới.
